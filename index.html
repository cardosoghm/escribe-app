Pantalla

Toques

Evita letras repetidas por toques dobles. Subilo si aparecen letras de más.

0 = toque normal. Subilo si roza letras sin querer. La letra se marca al levantar el dedo.

Predicción de palabras

Las palabras aprendidas aparecen primero. Una palabra que no está en el diccionario se sugiere recién cuando la usó 2 veces, para no aprender errores de tipeo.

Ojo: las sugerencias pueden influir en lo que elige. Si querés asegurarte de que todo lo escrito sea 100 % suyo, apagala.

Respuesta al tocar

Voz

0 = apagado (solo habla con el botón «Hablar»). Por ejemplo, con 3 segundos: termina de escribir, espera 3 segundos y la app dice la frase sola.

Para que la voz funcione sin internet: Ajustes de Android → Accesibilidad → Salida de texto a voz → descargar el idioma Español.

Bloqueo

PIN inicial: 0000. Cambialo. Para entrar acá: mantener apretada 3 segundos la esquina superior izquierda.

Historial

Se guarda solo en este dispositivo cada vez que toca «Hablar» o «Borrar todo».
